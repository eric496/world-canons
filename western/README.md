# The Western Canon

The art, buildings, ideas, books, music, faiths, science and history of the Western tradition, from ancient Greece to the present. Each section follows the same plan: the people, their key works and the movements they belonged to, all with biographies, introductions and as many pictures as copyright allows. The sections share one set of eras, so you can see that Vermeer, Spinoza and Huygens were working in the same small country in the same decade.
