# The East Asian Canon

The art, buildings, thought, literature, music, religion, science and history of China, Japan and Korea, from Shang bronzes to the present. These cultures shared a written language, Confucian and Buddhist ideas and a long conversation with each other, so each section follows all three side by side, with the same eras throughout. Names use pinyin for Chinese, Hepburn for Japanese and Revised Romanization for Korean, with the original script given on each person's page.
